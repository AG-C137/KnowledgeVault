# sponsrdump

## Достоинства

- простой код
- минимум зависимостей
- стабильная архитектура
- хороший Markdown
- хранит состояние
- удобный CLI

## Недостатки

- URL проекта должен нормализоваться автоматически
- нет режима ранней остановки поиска
- слишком тесно связаны получение данных и запись на диск

## Решение

Использовать как референс и источник идей.
Не делать форк.
При необходимости отправить небольшие исправления upstream.
