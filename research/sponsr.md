# Sponsr

Дата исследования: 2026-07-27

## Используемый инструмент

sponsrdump

## Структура архива

- 2363 HTML
- 722 WEBP
- 1 MP3

Архив плоский, без каталогов.

## HTML

Сохраняется только содержимое статьи.

Отсутствуют:

- <head>
- <title>
- <meta>
- <script>

Присутствуют:

- текст
- изображения
- ссылки
- iframe

## API

API возвращает значительно больше данных, чем сохраняет sponsrdump.

Например:

- post_date
- post_url
- project_title
- project_id
- level_name
- level_price
- post_views
- tags

## Вывод

Перед разработкой импортёра необходимо расширить формат экспорта sponsrdump, чтобы не терять метаданные.
