# AGENTS.md

## Назначение

Этот документ содержит инструкции для ИИ-ассистентов и разработчиков,
работающих над проектом KnowledgeVault.

---

## Общие принципы

- Не менять архитектуру без обсуждения.
- Предпочитать простые решения сложным.
- Не добавлять зависимости без необходимости.
- Не выполнять крупный рефакторинг вместе с новой функциональностью.

---

## Документация

- Документация является частью проекта.
- При изменении архитектуры обновлять PROJECT.md.
- README содержит только обзор проекта и инструкции по началу работы.
- ROADMAP отражает только планируемые задачи.

---

## Код

- Python 3.12+
- Стандартная библиотека предпочтительнее внешних зависимостей.
- Код должен быть понятным без дополнительных комментариев.
- Один модуль — одна ответственность.

---

## Работа с библиотекой

- Markdown является каноническим форматом хранения документов.
- SQLite, эмбеддинги, кэш и поисковые индексы являются производными данными.
- Производные данные должны полностью пересоздаваться из библиотеки.

---

## Импорт

При импорте материалов необходимо сохранять:

- текст;
- изображения;
- ссылки;
- дату публикации;
- автора;
- доступные метаданные.

Импорт не должен изменять смысл исходного документа.

---

## Git

- Небольшие коммиты.
- Осмысленные сообщения.
- Один коммит — одна логическая задача.

---

## Главное правило

Если возникает выбор между удобством реализации и сохранностью данных,
предпочтение всегда отдаётся сохранности данных.
