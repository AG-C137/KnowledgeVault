## KnowledgeVault — состояние проекта (июль 2026)

### Цель проекта

Создать локальную систему долговременного хранения знаний.

KnowledgeVault **не является загрузчиком данных**. Он получает данные из внешних источников и превращает их в единое индексируемое хранилище.

Основные функции:

- долговременный архив;
- полнотекстовый поиск;
- семантический поиск;
- работа с локальными LLM;
- интеграция с Obsidian;
- независимость от облачных сервисов.

---

### Основная архитектура

```
Источник
      │
      ▼
Downloader
(sponsrdump, yt-dlp, ...)
      │
      ▼
Raw Archive
      │
      ▼
KnowledgeVault Importer
      │
      ▼
SQLite + FTS5 + Embeddings
      │
      ├── Obsidian
      ├── RAG
      └── Local LLM
```

Главная идея:

> KnowledgeVault ничего не скачивает самостоятельно.

Каждый источник имеет собственный downloader.

Не форкать `sponsrdump`.

Использовать его как внешний инструмент.

KnowledgeVault занимается только импортом результатов.
